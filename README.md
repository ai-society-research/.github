# AI Society Research

Изучаем практики использования искусственного интеллекта жителями мегаполиса и цифровой дискурс об ИИ. В наших репозиториях вы найдете наборы текстовых данных из социальных медиа и результаты опросов жителей Санкт-Петербурга, инструменты для сбора и анализа текстов, а также интерактивные материалы исследования.

Работа ведётся в рамках проекта [«Дифференциация практик использования технологий искусственного интеллекта в среде жителей мегаполиса: социологический анализ»](https://rscf.ru/project/25-28-00217/).

## Данные и результаты

- **[survey-data](https://github.com/ai-society-research/survey-data)** — данные двух волн опросов, проведённых в 2025 и 2026 годах. В репозитории опубликован [интерактивный отчёт](https://ai-society-research.github.io/survey-data/), в котором представлены результаты опросов и их сопоставление с анализом цифрового дискурса.
- **[tg-data](https://github.com/ai-society-research/tg-data)** — набор данных из тематически релевантных Telegram-каналов: публикации, комментарии и сопровождающие сведения об источнике и времени размещения. Состав файлов и структура записей описаны в README репозитория.

## Программные инструменты

- **[ai-discourse-analyzer](https://github.com/ai-society-research/ai-discourse-analyzer)** — модуль AIDA, разработанный в рамкох данного проекта и предназначенный для работы с текстовыми корпусами: тематическая кластеризация, извлечение биграмм, гибридная модель анализа тональности. [Демонстрация работы модуля](https://frantsuzova.github.io/ai-discourse-analyzer/) представлена отдельно от итогового отчёта исследования.
- **[corpus_cluster_explorer](https://github.com/ai-society-research/corpus_cluster_explorer)** — инструмент для кластеризации текстовых корпусов.
- **[tg_scrape_module](https://github.com/ai-society-research/tg_scrape_module)** — модуль сбора материалов из Telegram.

В организации также ведётся **review-parser** — закрытый служебный репозиторий парсера отзывов RuStore с поддержкой постраничного сбора. Доступ к его материалам ограничен.

Подробности о составе наборов данных, порядке их использования и работе программных инструментов приведены в README соответствующих репозиториев.
